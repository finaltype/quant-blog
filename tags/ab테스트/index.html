#A/B테스트 태그 글 모음

'A/B테스트' 태그가 붙은 글 3편.

  • LLM 온도 파라미터 유실 사고 - A/B 테스트가 처음부터 무효였던 이유
    상위 함수에 값을 넘겼다는 것과, 그 값이 실제로 서버에 도착했다는 것은 다른 문장이었습니다
  • 미국장 시세 반영 A/B 테스트, 하루에 버그 세 개를 연달아 밟았다
    프롬프트 한 줄을 추가할지 말지 가리는 실험을 돌렸는데, 실험 자체보다 실험을 돌리는 장치에서 결함이 세 번 터져 나왔습니다.
  • 주말 A/B 테스트 결과 판정 + 실행 파이프라인 안정성 보강
    성과가 더 좋아 보이는 표본에 속지 않게 결과를 정리하고, 실행 계측을 함께 보강했습니다
