#안전장치 태그 글 모음

'안전장치' 태그가 붙은 글 12편.

  • 주문 실행·안전장치 계층 확장과 사전등록 A/B 실험 틀 구축
  • 계좌 입출금 반영 로직을 앞당겨 구현하고 같은 날 배포했다
  • 현금 부분충전 매수 적용과 프롬프트 A/B 실험 사전등록
  • 출력 토큰 상한 적용과 주문 장부대조 가드 확장
  • 안전장치를 겹겹이 쌓고, 전제를 다시 검증한 한 주
  • 주문 식별 로직 마무리와 비대해진 작업 문서 다이어트
  • 서버가 조용히 망가지는 문제 - 감지·격리·복구 안전장치를 만든 하루
  • 측정·검증 도구 자체의 결함을 연달아 찾은 한 주
  • 외부 시세 데이터가 통째로 비어버린 날 - 유니버스 오염 사고
  • 공유계좌 실거래 전환 - 계좌 구분값 누락이 반복해서 문제를 일으켰다
  • 킬스위치 사고 사후검토 - 증상만 지웠던 원인이 남아있었다
  • 킬스위치 오발 - 계좌 구분값 누락이 부른 실거래 정지 위험
