#장애대응 태그 글 모음

'장애대응' 태그가 붙은 글 8편.

  • 거래소 접속차단부터 GPU 제거까지 - 장애 원인을 끝까지 추적한 한 주
    거래소 접속 차단으로 생긴 크래시를 조용한 실패로 낮추고, 수동 주문으로 1주 실거래 매수팔기 테스트를 마쳤습니다. 반복되던 토큰 폐기 버그는 재시작 순서 어긋남이 원인이었고, 보조 그래픽카드 정리는 절반에서 멈추지 않고 끝까지 밀어붙였습니다.
  • Toss 토큰 폐기 재발 원인 - 상주 두 개 재시작 시점 어긋남
    외부 시세 API 토큰이 자꾸 무효화되는 문제의 원인을 찾아 고쳤고, 신규 거래소 진입 실험은 기준 미달이지만 최종 판정까지 기다리기로 했습니다.
  • KRX 접속 차단 - 라이브러리 임포트 크래시를 로그인 실패로 강등
    거래소 접속이 막히자 데이터 라이브러리를 불러오는 순간 프로세스가 통째로 죽는 버그가 터졌고, 같은 날 새 리서치 가설 하나를 사전등록부터 병합까지 끝냈습니다.
  • 서버가 조용히 망가지는 문제 - 감지·격리·복구 안전장치를 만든 하루
    어제 발견한 뉴스 입력 사고를 마무리하자마자 새로운 결함이 나타났고, 재발 방지 장치를 하루 만에 만들었습니다.
  • AI 판단 모델 샘플링 설정 점검 - 의도와 다른 값으로 돌고 있었다
    AI 리포트용 모델들이 몇 주째 의도한 것과 다른 샘플링 설정으로 돌고 있었다는 걸 발견해 바로잡았고, 지난주 그래픽카드 장애의 후속 안전장치도 마무리했습니다.
  • VRAM 정리 패치가 저녁 프로덕션 장애로 되돌아온 하루
    낮에 적용한 GPU 메모리 정리 패치가 저녁 프로덕션 3연속 실패로 돌아왔고, 별도로 증권사 API 페이지네이션 버그도 하나 잡았습니다
  • 재발한 원장 오염과 자동화 함정을 뿌리부터 추적한 한 주
    이틀 연속 재발한 원장 오염 사고의 뿌리를 결국 찾아냈고, 그 사이 장중 관측 파이프라인과 GPU 확장으로 새 실험 트랙도 열었습니다
  • 상주 프로세스 재시작 누락과 모의계좌 원장 오염, 하루 새 겹친 두 장애
    며칠째 조용히 멈춰 있던 갱신 프로세스와 증권사 API 스케일 오류가 만든 원장 오염 사고
