#버그수정 태그 글 모음

'버그수정' 태그가 붙은 글 10편.

  • 토큰 핑퐁과 야간배치 행 - 두 번의 근본원인 추적
    인증 토큰이 서로를 계속 무효화하던 문제와 야간 배치가 밤새 멈춰 있던 문제, 두 운영 사고를 추적해 고치고 재발방지까지 자동으로 확인하게 만들었다.
  • TA 배치 밤새 멈춤 원인 - 타임아웃 없는 외부 호출 2건
    밤사이 종목평가 배치가 멈춰 있었던 원인을 찾아 고쳤는데, 재발방지가 충분한지 되짚어보니 같은 유형의 구멍이 하나 더 있었다.
  • Toss 토큰 401 핑퐁 근본원인 - 캐시 재확인 없는 즉시 재발급
    아침마다 되풀이되던 Toss API 토큰 무효화 소동의 진짜 원인을 찾아 고치고, 재발 여부를 사람이 기억하지 않아도 자동으로 확인하게 만들었다.
  • 미국장 시세 반영 A/B 테스트, 하루에 버그 세 개를 연달아 밟았다
    프롬프트 한 줄을 추가할지 말지 가리는 실험을 돌렸는데, 실험 자체보다 실험을 돌리는 장치에서 결함이 세 번 터져 나왔습니다.
  • 킬스위치 오발 - 계좌 구분값 누락이 부른 실거래 정지 위험
    정보용 모의 틱이 실계좌 킬스위치와 같은 이름공간을 공유하면서, 무관한 계좌 잔고로 계산한 가짜 손실이 월요일 실거래를 막을 뻔했습니다.
  • 이관 방지 플래그가 다른 계좌 매물을 잘못 건드린 사고
    한쪽 계좌 재매수를 막으려고 걸어둔 플래그가 전역으로 적용되면서, 방금 이관받은 다른 계좌 종목을 도로 강제매도시키고 있었습니다. 같은 날 성능 최적화 자동화 도구도 하나 새로 완성했습니다.
  • 두 번째 증권사 병행운영을 시작하며 잡아낸 조용한 버그들
    이번 주 가장 큰 진전은 새 증권사 실계좌 검증과 모의투자 병행운영 개시였고, 그 사이사이에서 며칠씩 티 안 나게 실패하던 버그를 여럿 걷어냈습니다
  • 판정 조건이 몇 달째 성립을 못 하길래, 수동 확인을 자동 센서로 바꿨다
    시장 레짐 자동 감시와 AI 재검토로 찾아낸 야간 감시 공백 두 건
  • 새 로컬 모델로 정식 전환, 그 옆에 예전 모델을 조용히 얹었다
    몇 주 끌어온 모델 비교를 끝내고 전환을 확정한 날, 완주 판정 버그 하나도 함께 잡았다
  • 백로그 전수분류로 찾아낸 며칠째 조용히 죽어있던 버그들
    작업 목록을 처음부터 끝까지 다시 훑다가 여러 날 동안 티 안 나게 실패하던 기능 두 개를 발견했고, 두 번째 증권사 모의투자 병행운영도 시작했습니다
