#운영 태그 글 모음

'운영' 태그가 붙은 글 15편.

  • 야간 배치 작업 26시간 멈춤 - 타임아웃 없는 외부 API 호출 하나가 원인
    처음 고친 줄은 맞았지만 같은 함수 안의 폴백 경로 하나를 놓쳐서, 재발 방지가 반쪽짜리였던 사고를 기록한다
  • 리서치 스크립트의 대량 조회가 실거래 라운드를 크래시시킨 사고 - 원인은 임포트 시점 네트워크 호출
    연구용 백필이 외부 API 차단을 유발했고, 그 차단이 라이브러리 임포트 단계에서 실거래 프로세스를 통째로 죽였습니다
  • 수동 실행이 예약 실행으로 오판된 버그 - systemd 활성화 메타데이터가 생각보다 오래 남았다
    한 달 전에 고쳤다고 믿은 버그가, 완전히 다른 원인으로 다시 터졌습니다
  • 개발일지 자동화가 한 달 가까이 멈춰 있었던 이유
    로그조차 안 쌓이니, 돌고 있는지 죽어 있는지 구분할 방법이 없었습니다
  • 성과 벤치마크 재정의 - 기간 불일치 착시를 종목선택 효과 지표로 교체
    실계좌 성과 리포트가 지수 대비 큰 손실처럼 보이던 건 분자와 분모를 서로 다른 기간으로 잰 착시였다. 벤치마크를 로트별 같은 보유기간 비교로 다시 정의하고, 정직하게 재니 종목선택의 우위가 사실상 0이라는 더 불편한 질문과 마주했다.
  • 토큰 핑퐁과 야간배치 행 - 두 번의 근본원인 추적
    인증 토큰이 서로를 계속 무효화하던 문제와 야간 배치가 밤새 멈춰 있던 문제, 두 운영 사고를 추적해 고치고 재발방지까지 자동으로 확인하게 만들었다.
  • TA 배치 밤새 멈춤 원인 - 타임아웃 없는 외부 호출 2건
    밤사이 종목평가 배치가 멈춰 있었던 원인을 찾아 고쳤는데, 재발방지가 충분한지 되짚어보니 같은 유형의 구멍이 하나 더 있었다.
  • Toss 토큰 401 핑퐁 근본원인 - 캐시 재확인 없는 즉시 재발급
    아침마다 되풀이되던 Toss API 토큰 무효화 소동의 진짜 원인을 찾아 고치고, 재발 여부를 사람이 기억하지 않아도 자동으로 확인하게 만들었다.
  • 거래소 접속차단부터 GPU 제거까지 - 장애 원인을 끝까지 추적한 한 주
    거래소 접속 차단으로 생긴 크래시를 조용한 실패로 낮추고, 수동 주문으로 1주 실거래 매수팔기 테스트를 마쳤습니다. 반복되던 토큰 폐기 버그는 재시작 순서 어긋남이 원인이었고, 보조 그래픽카드 정리는 절반에서 멈추지 않고 끝까지 밀어붙였습니다.
  • 보조 그래픽카드 제거 - 레지스트리 fail-loud가 영향 범위를 바로 알려줬다
    일주일 관찰 후 판매할 보조 그래픽카드를 재부팅 전에 뽑았는데, 설계해 둔 적색 경보가 그 즉시 영향 범위를 정확히 짚어줬습니다.
  • Toss 토큰 폐기 재발 원인 - 상주 두 개 재시작 시점 어긋남
    외부 시세 API 토큰이 자꾸 무효화되는 문제의 원인을 찾아 고쳤고, 신규 거래소 진입 실험은 기준 미달이지만 최종 판정까지 기다리기로 했습니다.
  • 실거래 1주 매수팔기 테스트 경로 확정 - 자동화 대신 수동주문으로
    내일 장중에 한 주를 사고파는 작은 실거래 테스트를 하기로 하면서, 퇴역해둔 자동 경로 대신 수동 주문을 선택한 이유를 정리했습니다. 오늘 쌓인 여러 변경도 모아서 상주 프로세스를 재시작했습니다.
  • 블로그 주간 리포트 5주째 스킵 - 죽은 계좌 참조가 원인
    E1 주간 리포트가 5주 연속 스킵된 원인을 추적했더니, 계좌 이전 후에도 리포트가 예전 계좌 상태만 보고 있었습니다.
  • 안전장치를 겹겹이 쌓고, 전제를 다시 검증한 한 주
    서버 퇴화 감지부터 GPU 죽은 슬롯 감지까지 안전장치를 여러 겹 쌓았고, 그 사이사이 "고친 게 정말 원했던 걸 이뤘나"를 다시 검증해 틀린 전제를 찾아냈습니다.
  • self-ρ 측정 전면 퇴역과 테스트발 원장 오염 발견
    자원 낭비로 판단한 측정 하나를 완전히 껐고, 그 과정에서 테스트가 실거래 원장에 가짜 기록을 남기고 있던 걸 찾아 정리했습니다.
