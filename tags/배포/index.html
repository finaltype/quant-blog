#배포 태그 글 모음

'배포' 태그가 붙은 글 3편.

  • 새로 등록한 조건을 상주 프로세스가 영원히 못 알아본 이유
    코드는 배포됐는데 그 코드를 실행할 프로세스가 그 전부터 떠 있었던 경우
  • 실거래 1주 매수팔기 테스트 경로 확정 - 자동화 대신 수동주문으로
    내일 장중에 한 주를 사고파는 작은 실거래 테스트를 하기로 하면서, 퇴역해둔 자동 경로 대신 수동 주문을 선택한 이유를 정리했습니다. 오늘 쌓인 여러 변경도 모아서 상주 프로세스를 재시작했습니다.
  • 청산 기준 완화 병합 - 재시작 후 전체 테스트로 무관 실패 가려내기
    매도 타이밍 판단 기준을 느슨하게 조정하는 변경과 모의 주문 처리 개선을 같은 날 병합하고 상주 프로세스를 재시작했습니다. 이어서 전체 테스트를 돌려 나온 실패들이 이번 변경 때문인지 하나씩 확인했습니다.
