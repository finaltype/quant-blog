#코드리뷰 태그 글 모음

'코드리뷰' 태그가 붙은 글 8편.

  • 계좌 간 자금 이동 기능 - 코드리뷰가 두 번 잡아낸 자금 불일치 위험
  • 증권사 경로 단일화 - 모의 계좌 비교 시스템을 새로 갈아끼웠다
  • 계좌 입출금 반영 로직을 앞당겨 구현하고 같은 날 배포했다
  • 동점 점수 처리 로직 교체 - 기각된 방식에서 새 방식으로
  • 구조 자문 리팩터링 4단계 실행과 사후검증, 그리고 재시작 자동화
  • 품고 있던 의심 두 가지, 검증해보니 둘 다 틀렸다
  • 첫 실주문 앞에서, 코드가 반대표를 던졌다
  • 한국어로 물었는데 영어로 답했다 — 그리고 코드 감사 시즌
