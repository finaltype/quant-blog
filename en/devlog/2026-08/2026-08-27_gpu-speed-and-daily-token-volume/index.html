Local LLM Speed by GPU Generation, and Our Production's Daily Token Volume

Checked with real logs instead of gut feeling

In my last post(new tab) I talked about switching to the RTX 5090. This time I'm going a bit more quantitative — how much did speed actually change with each hardware generation, and how many tokens does this project's local LLM actually process per day, based on real logs.

The hardware I've gone through, and measured runtimes

This bot's local LLM card has gone through one RTX 4070 Ti Super → two → one RX 7900 XTX → one RTX 5090.

With just one card (16GB), the model I was using back then simply didn't fit in memory at all. Combining two cards (32GB, tensor-split) got it running, and the nightly batch that analyzes the full stock universe finished in 5.81 hours.

I later switched to a single XTX (24GB), and the same batch took 6.15 hours — nearly the same. Since one card was replacing what two used to do, I adopted that setup at the time.

Per-card local LLM speed — a public reference

I've never had multiple cards side by side to benchmark myself, so instead here's a public cross-GPU benchmark thread as reference. These are token generation speeds for a same-class open-source dense model (source: arca.live cross-GPU thread(new tab); context depth wasn't controlled in this measurement, so treat it as a reference only).

Card Tokens/sec (approx.)
RTX 3090 40-45
AMD R9700 56
RTX PRO 6000 Max-Q 70
RX 7900 XTX 71
RTX 5090 80

You can see roughly a 1.1x to 2x spread across cards. In actual operation, though, that multiplier didn't translate directly into a shorter total batch time — as the XTX measurement above (6.15 hours) shows. Factors other than raw decode speed, like parallelism and wait time, are mixed in.

Daily token volume

This project has an AI pipeline that analyzes stocks with a local LLM(new tab). Multiple agent nodes read news, filings, and fundamentals to build their reasoning, and each node makes its own LLM call.

Averaging real logs from the past several weekdays, local LLM calls run about 5,200 times a day, totaling roughly 55 million input tokens and 7.5 million output tokens. That scale, just from generating daily reports, wasn't something I had a real feel for until I actually looked at the logs.
